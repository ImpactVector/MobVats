# Configuration examples

These source-controlled samples illustrate server JSON schemas. They are documentation, not automatically loaded runtime data. Copy/adapt deliberately; preserve authored server defaults and overrides.

| Sample | Intended use |
|---|---|
| [CULTURE_PROFILES.example.json](CULTURE_PROFILES.example.json) | Culture configuration under config/mobvats/culture/ |
| [MIXER_RECIPES.example.json](MIXER_RECIPES.example.json) | Mixer definitions under config/mobvats/mixer/ |
| [PASSIVE_DEFAULTS.example.json](PASSIVE_DEFAULTS.example.json) | Passive profile/default schema under config/mobvats/passive_mobs/ |
| [RESOURCE_PROFILES.example.json](RESOURCE_PROFILES.example.json) | Generic specimen resource/profile examples |
| [VANILLA_DEFAULTS.example.json](VANILLA_DEFAULTS.example.json) | Reference vanilla catalog; existing server defaults are not regenerated |

See [processing](../04-PROCESSING.md) for current behavior. Some samples record earlier defaults; samples are not a claim that every illustrated policy is the current bundled value. Compare with bundled resources/parser validation when authoring overrides.
