MobVats Slice 12.2 - Culture fouling and Mixer filtration

Vat medium persists one selected clean FluidStack prototype, its dirty counterpart,
and separate clean/dirty mB amounts. Both fractions share the calculated capacity;
level fill and reach exposure use their total. Fouling converts volume without
consuming or adding medium. A fully dirty vat retains its clean identity/profile.
Only the exact selected clean/dirty pair can refill a nonempty vat. Drains export
dirty first, including partial tails, then clean. The Output Fluid Port and bucket
path use that same Drain Valve boundary. Unrelated culture formulas never blend.

Recognized biological work converts 50 mB by default: completed juvenile growth,
committed accelerated secondary output, sheep regrowth after its feed transaction,
and committed accelerated configured resource processes. Failed, blocked, unfed,
mechanical, transfer, and individual Tool Port strike paths do not foul. Conversion
and output changes participate in the same reversible transaction. Growth fires
once on completion. Partial clean tails convert only their remaining volume;
fully dirty, dry, unrecognized, and unknown-formula media do not block production.

Dirty formulas add 100 mB mobvats:waste by default. This quantity describes a formula
entry, independently of the volume converted by an action. Compound media retain
their family, unrelated components, and full canonical formula. Ordinary medium
wraps in culture_slurry with 1000 mB of its actual exact raw fluid ID plus waste;
profile tags never replace the actual fluid. Compound formulas are not nested.
Unknown world-spill formulas cannot be reconstructed by fouling or filtration.

Culture configuration: config/mobvats/culture/*.json
  Rule fields: frequency (clean), dirty_frequency (fully dirty).
  Bundled ordinary endpoints: 1.00 / 0.75; enriched endpoints: 5.00 / 2.75.
  Dry: 0.50. Rules resolve against the persisted clean prototype even at 0 clean mB.
  Mixed frequency = (clean mB * clean rate + dirty mB * dirty rate) / total mB.
  Existing reach interpolation and happiness/yield remain unchanged.
  Optional root configuration:
    "fouling": {
      "waste_formula_mb": 100,
      "default_mb": 50,
      "actions": {
        "mobvats:growth": {"fouling_mb": 25},
        "mobvats:shear_regrowth": {"fouling_mb": 100},
        "example:biological_process": {"fouling_mb": 0}
      }
    }
  Resource process and secondary-output definitions also accept optional
  fouling_mb, which takes precedence over the action map/default. It must be a
  nonnegative integer; zero disables conversion. The accelerated flag identifies
  culture-sensitive configured processes, including ordinary media at 1x.
  Older authored rules lacking dirty_frequency retain their authored frequency
  at both endpoints. Untouched bundled 12.1 culture defaults upgrade automatically;
  user-modified defaults and overrides are preserved.
  Existing stored dirty prototypes remain stable across config reloads; a changed
  waste_formula_mb applies when establishing a new pair in an empty vat.

Mixer configuration: config/mobvats/mixer/*.json
  Item/fluid inputs accept record_in_composition (default true). False consumes
  the input normally but excludes its formula contribution. Filter materials and
  fluid reagents can both use this option.
  Optional transform:
    "transform": {
      "source_input": 0,
      "remove": [{"kind":"FLUID", "selector":"mobvats:waste"}],
      "restore_ordinary": true
    }
  source_input selects one recorded compound-fluid input (default index 0).
  required/excluded optionally contain composition entries with kind, selector,
  and amount. Removal selectors remove entire matching entries; every removal
  must match the source formula. Tags/custom selectors retain their authored
  meaning and are never guessed or expanded into exact resources.
  Source chunks must represent one exact formula; physical splits are supported,
  but unrelated formulas cannot combine to make a filter batch. The source family
  and unrelated components survive. Additional recorded inputs follow normal
  canonical composition rules. Explicit composition and transform are exclusive.
  restore_ordinary unwraps only culture_slurry with the ordinary wrapper's single
  1000 mB exact fluid entry and no other ingredients. The component_fluid family remains compound,
  as do tag-only, custom, and alternative formulas.
  Volume and time are output_amount/batch_ticks; they are not engine constants.

Bundled recipes:
  mobvats:filter_general: 1000 mB dirty culture + 1 charcoal -> 1000 mB clean,
    100 ticks, excludes exact lava-based formulas. End/other cultures use this path.
  mobvats:filter_lava: 1000 mB dirty lava culture + 1 sand -> 1000 mB clean,
    100 ticks, requires lava in the formula.
  Both preserve arbitrary valuable additives, remove waste, and safely restore
  vat-generated ordinary fluid wrappers. Filter materials never become additives.
  No separate waste output is emitted. Untouched old bundled Mixer defaults upgrade
  automatically; authored defaults remain unchanged and can use the examples.
  A Mixer remembers which ordinary fluids it actually restored so output ports
  can export them after save/load without classifying every raw input as an output.

Persistence/recovery:
  Slice-12.1 Fluid NBT loads entirely clean, preserving every component, amount,
  over-capacity state, legacy migration flag, diagnostics, and retained conflicts.
  Modern saves persist both prototypes/fractions and full conflicting pairs.
  Compatible reconnection merges corresponding fractions only. Incompatible pairs
  remain in the existing sequential drain recovery queue, including dirty volume.
  Dirty stacks retain formula/components in buffers, conduits, ports, buckets,
  Mixer processing, NBT, and network serialization. World placement remains lossy:
  only registered family survives; recollection does not recover composition.

Status shows clean culture name, clean/dirty mB, dirty percentage, total/capacity,
and mixed frequency before reach exposure. cultureFouledMb/foulingEvents count
actual successful conversions; cultureFilteredMb counts committed filter volume.

No bridge networks, arbitrary chemistry, foul slurry, size changes, quality axis,
hostile progression, lightning, evaporation, or per-tick medium consumption.
